# Personalized Educational Game in Human-Agent Systems

**基于 Unity 的个性化隐私教育游戏｜爱丁堡大学人工智能 MSc 毕业论文｜2022**

[毕业论文（PDF）](./Informatics_MSc_Dissertation.pdf)

## 项目简介

本项目通过情境问答与游戏化交互，帮助玩家理解物联网（IoT）设备的数据收集行为，了解自身隐私偏好，并学习相关隐私知识。

项目使用 Unity 与 C# 开发，包含情境问答、知识测验、提示、积分、商店、三消小游戏及个性化结果展示，是我在爱丁堡大学人工智能硕士期间完成的毕业论文项目。

## 主要功能

- **隐私情境问答**：围绕 6 类地点设计 75 个数据收集情境，记录玩家的舒适度及允许／拒绝数据收集的选择。
- **知识测验与提示**：结合 IoT 设备知识设置测验与分级提示，通过积分和商店衔接学习与游戏流程。
- **个性化反馈**：分析玩家回答与情境因素之间的相关性，以图表展示隐私偏好、测验表现及提示使用情况。
- **三消小游戏**：作为问答之外的可选玩法，提供额外的积分获取途径。
- **进度保存与恢复**：通过 JSON 存储玩家信息、回答记录、积分及测验状态，支持恢复游戏进度。

## 技术实现

- **界面与动画**：使用 Unity UGUI 构建界面，通过自定义 Button 派生组件复用交互逻辑，并使用 DOTween 实现界面过渡与动画。
- **流程控制**：实现场景切换、情境文本展示、问答、提示、积分及结果反馈流程。
- **数据持久化**：使用 C# 数据结构与 Unity JsonUtility 保存和读取玩家状态。
- **事件分发**：使用 C# 委托实现事件注册与分发，连接三消玩法中的消除、积分等逻辑。
- **对象池**：使用基于队列的 GameObject 对象池管理小游戏特效的创建、激活与回收。
- **统计分析**：使用 Math.NET Numerics 计算 Spearman 秩相关系数，分析情境因素与玩家隐私选择的关联，生成个性化反馈。

## 用户评估

项目开展了小规模用户研究，共招募 7 名参与者，其中 6 人完成游戏。收集到的 5 份系统可用性量表（SUS）反馈，平均得分为 **71.6／100**。

该研究用于初步评估系统可用性并收集改进建议；受样本规模限制，结果不代表已经验证普遍性的学习效果。
